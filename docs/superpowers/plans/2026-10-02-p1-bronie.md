> Stan: 2 października 2026 (noc). Wykonawca: Claude w worktree `p1-weapons` (gałąź `p1-weapons` od `pietro-1` @ `aa7c36f`), równolegle z agentami piętra, percepcji i zapisu postępu.

**Cel:** trzy bronie, które czują się zupełnie inaczej niż pięć istniejących (precyzja, przyszpilanie, salwa), siedem rodzajów zamków z jednym czytelnym językiem (wygląd, dźwięk, napis), i pomysł właściciela: **każdy poziom ulepszenia widać na broni**, a pełne ulepszenie daje wykończenie mistrzowskie.

**Architektura:** jak dotąd — węzły z kodu, liczby w `.tres`, czysta logika w `RefCounted` testowana bez sceny (`LockRules`, `LockTally`, `HarpoonRules`, `WeaponLook`), efekty przez `Fx`/`Sfx`/`Events`. Ulepszenia działają na kopii danych broni. Modele z Blendera mają **nazwane części** (`upg_*`, `bolt`, `head`, `rocket_1`…); logika nie zależy od modeli (greybox zawsze działa).

**Praca równoległa:** modele w Blenderze robią podagenci (każdy we własnych plikach `tools/art/models/*.py`, bez Godota, bez commitów); ja integruję, importuję i commituję. Wspólne rejestry (`ALL` w `build_models.py`, `ArtLibrary.REGISTRY`, `locale/strings.csv`, `Events`) — tylko dopisywanie na końcu.

## Zadanie 3: Sztucer ekspedycyjny (`rifle_hunt`, slot 6)

`Hitscan.pierce(space, from, to, max_targets) -> Array[Dictionary]` — trafienia po kolei: hurtbox każdego **odbiorcy** liczony raz (pierwsza strefa, przez którą przeszedł promień, decyduje o słabym punkcie), kolejne strefy tego samego odbiorcy pomijane; ściana kończy promień (ostatni wpis z `hurtbox == null`).

```gdscript
static func pierce(space: PhysicsDirectSpaceState3D, from: Vector3, to: Vector3, max_targets: int) -> Array[Dictionary]:
	var out: Array[Dictionary] = []
	var receivers: Array[Node] = []
	var start := from
	var skipped: Array[RID] = []
	for step in max_targets * 6 + MAX_SKIPPED_AREAS:
		var hit := ray(space, start, to, skipped)
		if hit.is_empty():
			break
		var hurtbox: Hurtbox = hit["hurtbox"]
		if hurtbox == null:
			out.append(hit)   # a wall ends the shot
			break
		skipped.append(hit["rid"])
		if not receivers.has(hurtbox.receiver):
			receivers.append(hurtbox.receiver)
			out.append(hit)
			if receivers.size() >= max_targets:
				break
	return out
```

`WeaponHolder._attack`: gdy `pierce_targets > 1`, zamiast `Hitscan.ray` idzie `Hitscan.pierce`; obrażenia 85 na każdy cel (bez spadku), smuga do ostatniego punktu. Widok (`ViewmodelRig`): po strzale zamek odchyla się (obrót wokół osi lufy), cofa i wraca w czasie cyklu (`cooldown`), prawa dłoń jedzie za znacznikiem `BoltKnob`; przeładowanie: broń przechyla się, zamek otwarty, łódka (`clip`) z 5 nabojami zjeżdża w komorę. Dźwięki `rifle_hunt` (strzał z echem), `rifle_bolt` (klak-klak zamka po 0,25 s).

**Testy:** 85 obr.; słaby punkt ×3 (255); trzy manekiny w linii — wszystkie trafione, czwarty nie; ściana za pierwszym zatrzymuje; dwie strefy tego samego celu = jedno trafienie; cykl 1,0 s (drugi strzał po 0,95 s odmówiony, po 1,0 s przyjęty); magazynek 5, zapas 25/40.

## Zadanie 4: Harpunnik (`harpoon`, slot 7)

**`HarpoonRules`** (czysta):

```gdscript
enum Verdict { DAMAGE, PIN, PULL }
static func verdict(max_health: float, knockback_resist: float, wall_distance: float, data: WeaponData) -> Verdict:
	if max_health <= data.pin_max_health and wall_distance <= data.pin_reach:
		return Verdict.PIN
	if max_health <= data.heavy_health and knockback_resist < HEAVY_RESIST:
		return Verdict.PULL
	return Verdict.DAMAGE
## Push speed that slides a body pull_distance metres against the ground
## friction (v^2 = 2 a d), before its knockback resistance.
static func pull_speed(distance: float, resist: float) -> float:
	return sqrt(2.0 * Enemy.GROUND_FRICTION * distance) / maxf(1.0 - resist, 0.25)
```

## Odstępstwa i doprecyzowania

- **Łańcuch przyjmuje tylko „ciężkie” narzędzia** (strzelba, pięści) — tak jak mówi napis. Suma z 0,4 s dotyczy strzelby (śrut z dystansu, dwie lufy). Pistolet, kartaczownica, sztucer krzeszą iskry.
- **Spękany mur:** „wybuch ≥ 40” liczony jako suma obrażeń wybuchowych w 0,3 s — pojedyncza rakieta skrzyni (22 + 14) nie wystarcza, dwie z jednej salwy tak; raca z podwójną lufą (odstęp 0,45 s) nie sumuje się, liczy się jako trafienie „z bliska” (≤ 5 m od strzelającego), trzy takie kruszą mur.
- **Przyszpilenie** zabija na pewno (bez względu na pozostałe zdrowie), bo to finał efektowny; „lekki” = maks. zdrowie eksponatu ≤ 60 (90 z Zadziorami) — figura woskowa w pełni (75 HP) jest już „średnia”.
- **Ciężki** dla harpuna: maks. zdrowie > 150 albo opór odrzutu ≥ 0,75, oraz każdy cel, który nie jest zwykłym eksponatem (strażnicy, T-Rex).
- **Sztucer:** przeładowanie 2,2 s (projekt nie podaje) — łódka 5 nabojów.
- **Rakiety:** „ogień” = obrażenia od ognia (wosk ×2) i krótkie płonięcie 3/s przez 2 s bez światła (sześć świateł na salwę to za dużo).
- **Klawisze dev** piaskownicy 7/8/9/0 → F5–F8, bo 6–8 to teraz bronie.
- `open_instantly()` nie emituje `opened` (stan z zapisu, bez efektów).
